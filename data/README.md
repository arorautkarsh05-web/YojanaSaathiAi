# YojanaSaathi AI — Verified Agricultural Data Repository

This directory contains the machine-readable, evidence-grounded dataset backing YojanaSaathi AI's deterministic rules, geographic resolution, and multi-scheme convergence engines.

## Directory Structure

```
data/
├── schemes/
│   ├── pm_kisan.json             # Pradhan Mantri Kisan Samman Nidhi
│   ├── pmfby.json                # Pradhan Mantri Fasal Bima Yojana
│   ├── pmksy_pdmc.json           # PM Krishi Sinchayee Yojana (Per Drop More Crop)
│   ├── kcc.json                  # Kisan Credit Card
│   ├── up_krishak_durghatna.json # UP Mukhyamantri Krishak Durghatna Kalyan Yojana
│   └── smam_machinery.json       # Sub-Mission on Agricultural Mechanization
│
├── district_metadata/
│   └── up_districts.json         # All 75 UP Districts and 6 Agro-Climatic Zones
│
└── policy_evidence/
    └── evidence_register.json    # Statutory pairwise convergence citations and evidence
```

## Data Provenance & Verification
- All schemes reflect official government gazettes, department circulars, and revised operational guidelines.
- Geographic boundaries strictly follow the Uttar Pradesh State Department of Agriculture classification.
- No synthetic or estimated values are included without explicit qualification.
