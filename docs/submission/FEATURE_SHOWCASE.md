## 1. Feature Highlights Matrix

| Capability | What It Does | Why It Sets YojanaSaathi Apart |
|---|---|---|
| **Conversational Hindi Intake** | Accepts unstructured speech/text in Hindi, English, Hinglish, Punjabi | Eliminates bureaucratic friction for low-literacy farmers; converts voice to structured profile |
| **Bigha Ambiguity Resolver** | Detects colloquial "Bigha" usage and warns about Pucca vs. Kachha variations across UP | Prevents statutory disqualification caused by arbitrary universal conversion factors |
| **3-Valued Deterministic Rules** | Evaluates statutory conditions strictly to `PASS`, `FAIL`, or `UNKNOWN` | Zero LLM hallucination; missing info is never assumed to be eligible; auditable decisions |
| **Pairwise Scheme Convergence** | Computes compatibility for every pair across all 6 schemes with citations | Rejects false transitivity; prevents double-dipping while unlocking synergistic multi-scheme benefits |
| **7-Stage Benefit Journey Tracker** | Progressively tracks citizen journey from intake to official disbursement | Transparently distinguishes between citizen assistance and official sovereign government approval |
| **Unified Document Deduplication** | Identifies shared documents (Aadhaar, Khatauni ROR, Bank Passbook) | Saves farmers multiple Tehsil/bank visits; one certified paper satisfies multiple simultaneous schemes |
| **Grounded Multilingual Q&A** | Answers citizen questions strictly referencing published official gazettes | Returns explicit `can_verify: false` if statutory evidence is absent; zero fabricated deadlines |
| **75-District Geo-Applicability** | Maps UP into 6 agro-climatic zones and district clusters with notified crops | Customizes advice for water-deficit belts (Bundelkhand) vs flood zones (Terai) |
| **Low-Bandwidth Rural Mode** | Automatically caches generated action plans in browser `localStorage` | Works without cellular connectivity in rural village environments |
| **Policy Impact Intelligence** | Simulates downstream impact across saved citizen plans when a rule changes | Keeps farmer advice synchronized with new government amendments and gazette notifications |
| **Dual Storage Compatibility** | Runs seamlessly on lightweight SQLite (zero-config demo) or clustered PostgreSQL | Facilitates rapid hackathon testing while guaranteeing cloud-scale enterprise readiness |

## 2. Interactive User Experience Capabilities
- High-contrast, WCAG 2.2 AA compliant palette (Forest Green `#1B4D3E`, Warm Cream `#FDFBF7`, Field Green `#85BB65`).
- Custom SVG & high-resolution illustration of UP agro-climatic zones with frosted-glass framing.
- Full keyboard navigation and visible focus rings on all interactive buttons and modals.
- Clean printable action plan stylesheet (`@media print`) stripping away UI chrome for crisp physical paper copies.
