# 🌾 YojanaSaathi AI (योजना साथी AI)

### Evidence-Grounded Farmer Benefit Intelligence & Multi-Scheme Convergence Platform

**Bridging the gap between farmers and government welfare through transparent, explainable and evidence-driven technology.**

YojanaSaathi AI is a farmer-centric welfare intelligence platform designed to help farmers discover relevant government schemes, understand their eligibility, identify missing requirements and navigate multiple benefits through a unified action plan.

Unlike conventional scheme discovery platforms, YojanaSaathi focuses on **deterministic eligibility evaluation, evidence-backed recommendations and multi-scheme convergence rather than generic AI-generated answers.**

## 🚨 1. The Problem We Are Solving

India has numerous central and state government welfare schemes designed to support farmers.

However, discovering and accessing these benefits remains challenging.

Farmers frequently encounter:

- Fragmented information across multiple government portals.
- Difficulty understanding complicated eligibility conditions.
- Uncertainty about which schemes match their agricultural needs.
- Repeated document submission requirements.
- Limited awareness of scheme convergence possibilities.
- Language and digital accessibility barriers.
- Confusion between eligibility, application and actual benefit approval.

### The fundamental problem

**Government benefits exist, but understanding which benefits a farmer can access, what conditions they must satisfy and how to proceed remains unnecessarily complicated.**

YojanaSaathi aims to simplify this entire journey.

---

## 💡 2. Our Solution

YojanaSaathi AI transforms fragmented government welfare information into an understandable, evidence-grounded farmer benefit intelligence system.

Instead of asking farmers to search through dozens of schemes individually, the platform follows their actual agricultural needs.

It helps answer four important questions:

1. Which government schemes are relevant to my needs?
2. Do I satisfy their eligibility requirements?
3. Can I potentially benefit from multiple schemes together?
4. What documents and next steps are required?

### Our Core Philosophy

**Need → Eligibility → Verified Schemes → Action Plan**

The platform does not promise government approval. It helps farmers understand potential eligibility and navigate official application channels with greater clarity.

## ⚡ 3. What Makes YojanaSaathi Innovative?

Our innovation is not simply putting an AI chatbot on top of government scheme information.

We have designed a structured benefit intelligence architecture combining deterministic rule evaluation, evidence traceability, multilingual interaction and multi-scheme convergence.

### Innovation 01 — Three-State Deterministic Eligibility Engine

Traditional discovery systems often provide recommendations without adequately explaining uncertainty.

YojanaSaathi evaluates individual eligibility conditions using three explicit states:

| State | Meaning |
|---|---|
| PASS | The available evidence satisfies the condition. |
| FAIL | The available evidence contradicts the condition. |
| UNKNOWN | Information is missing, insufficient or unverified. |

**Why this matters:**

A missing income certificate should not automatically be interpreted as proof of eligibility or ineligibility.

Our engine preserves uncertainty instead of manufacturing confidence.

Every assessment can explain which conditions passed, failed or require additional information.

### Innovation 02 — Evidence-Grounded Multilingual Assistant

The platform combines farmer-friendly interaction with structured eligibility evaluation.

Its objective is to make complex welfare information understandable across:

- Hindi
- English
- Hinglish
- Punjabi

The assistant helps users understand scheme conditions, required documents and next steps.

Important distinction: conversational assistance does not independently determine eligibility. The structured eligibility engine remains responsible for evaluating scheme rules.

### Innovation 03 — Pairwise Multi-Scheme Convergence Matrix

This is one of the central differentiators of YojanaSaathi.

Farmers may qualify for multiple government schemes, but individual eligibility does not automatically establish that benefits can be combined.

Our convergence architecture evaluates relationships between schemes.

It distinguishes:

- Potentially compatible schemes.
- Conflicting requirements.
- Duplicate-benefit risks.
- Shared eligibility evidence.
- Missing compatibility information.
- Combinations requiring official verification.

The objective is to move beyond isolated scheme recommendations towards a consolidated farmer benefit strategy.

### Innovation 04 — Unified Document Deduplication

Different schemes frequently request overlapping documents.

YojanaSaathi identifies common document requirements and consolidates them into a unified checklist.

For example, if multiple relevant schemes require the same landholding evidence, the farmer can understand that this document is relevant across those applications.

This reduces information repetition and helps farmers prepare more efficiently.

### Innovation 05 — Four-Stage Transparent Farmer Journey

Instead of presenting an overwhelming catalogue of government schemes, the platform organizes the experience into four understandable stages.

1. **Need Identification:** Understand the farmer's actual requirement.
2. **Eligibility Evaluation:** Evaluate applicable conditions.
3. **Scheme Discovery:** Present relevant schemes with supporting evidence.
4. **Action Planning:** Generate a consolidated checklist and application roadmap.

### Innovation 06 — Guest-First, Privacy-Conscious Architecture

Farmers should be able to explore government benefits without being forced to create an account.

YojanaSaathi supports guest-first discovery and minimizes unnecessary personal information collection.

The platform is designed around:

- No Aadhaar number collection for eligibility discovery.
- No mandatory phone number for guest exploration.
- Data minimization.
- Explainable eligibility results.
- Controlled access to authenticated features.

## 🆚 4. How YojanaSaathi Differs From Existing Technologies

Existing technologies solve important parts of the government welfare discovery problem.

However, they do not necessarily provide the same integrated workflow.

Our differentiation is in combining their useful capabilities into one structured experience.

| Capability | Government Scheme Portals | Generic AI Chatbots | Financial Calculators | YojanaSaathi AI |
|---|---|---|---|---|
| Government Scheme Information | Yes | Depends on sources | Limited | Evidence-grounded |
| Farmer-Centric Discovery | Varies | Conversational | Usually limited | Yes |
| Deterministic Eligibility Engine | Varies | Not inherently | Formula-dependent | Yes |
| PASS / FAIL / UNKNOWN Logic | Not universally available | Not inherently | Usually no | Yes |

| Unified Action Plan | Varies | Generated text | No | Structured workflow |
| Guest-First Discovery | Portal-dependent | Usually possible | Usually possible | Yes |

### How We Differ From Specific Existing Solutions

**1. Government Discovery Platforms — MyScheme**

MyScheme provides a centralized way to discover government schemes.

YojanaSaathi builds on the broader discovery problem by emphasizing:

- Structured three-state eligibility evaluation.
- Evidence traceability.
- Pairwise scheme convergence.
- Unified document preparation.
- Farmer-oriented action planning.

Our objective is not to replace official government portals, but to make navigating them easier.

**2. Generic AI Assistants — ChatGPT and Similar Systems**

General-purpose AI assistants can explain government schemes and answer questions.

However, a conversational answer alone is not a reliable substitute for an independently verifiable eligibility decision.

YojanaSaathi separates conversational assistance from deterministic business-rule evaluation.

This distinction helps reduce unsupported eligibility claims and makes individual decisions easier to inspect.

**3. Commercial Financial Calculators**

Financial calculators generally evaluate specific inputs against predefined formulas.

YojanaSaathi addresses a broader workflow:

- Multiple schemes.
- Different eligibility conditions.
- Evidence requirements.
- Potential benefit compatibility.
- Document consolidation.
- Official application guidance.

**Our core differentiation:**

We are not building another scheme directory, another chatbot or another calculator.

We are building a structured farmer benefit intelligence and convergence layer.

## 🔐 7. Security, Privacy & Trust

Security and data minimization are important architectural considerations.

### Implemented Security Mechanisms

- JWT-based authentication.
- Refresh-token rotation.
- Token replay detection.
- Session family revocation.
- Argon2id password hashing.
- Role-based access control.
- Protected API endpoints.
- Input validation.
- Controlled personal data handling.

### Privacy by Design

**1. Aadhaar Minimization**

The eligibility discovery workflow does not require users to provide or store their 12-digit Aadhaar number.

**2. Guest Access**

Farmers can explore scheme discovery and eligibility workflows without mandatory account creation.

**3. Data Portability**

Authenticated users have an account-data export mechanism.

**4. Data Erasure**

The application provides a mechanism for users to request account-data deletion.

**5. Explainability**

Eligibility decisions are supported by structured conditions rather than unexplained AI-generated conclusions.

Our privacy architecture is designed with the principles of India's Digital Personal Data Protection Act, 2023 in mind. Legal compliance must be assessed against the applicable law, rules and actual operational practices.

## 🚀 9. Running the Project Locally

### Prerequisites

- Python 3.11+ (use the version supported by the project dependencies).
- Node.js and npm.
- Git.

### Step 1 — Clone Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd YojanaSaathi
```

### Step 2 — Backend Setup

```bash
# Create virtual environment
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

Configure the environment variables using the supplied `.env.example`.

### Step 3 — Run Backend Tests

```bash
pytest backend/tests -v
```

### Step 4 — Start FastAPI

```bash
python -m uvicorn app.main:app \
  --app-dir backend \
  --host 127.0.0.1 \
  --port 8000 \
  --reload
```

API Documentation:

http://127.0.0.1:8000/docs

### Step 5 — Frontend Setup

Open another terminal:

```bash
cd frontend

npm install

npm run dev
```

Frontend:

http://localhost:5173

### Step 6 — Production Build

```bash
npm run build
```

For production deployment, follow the Docker and Nginx configuration documented in the repository.
